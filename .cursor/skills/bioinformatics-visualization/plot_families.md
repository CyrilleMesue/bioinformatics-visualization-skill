# Plot families and subtypes

Keep subtype rankings separate. Do not use a bar template for a survival question because the bar template scored higher in another family.

- Bars: simple, grouped, stacked, ranked, paired
- Boxes: independent, paired, grouped, longitudinal
- Heatmaps: expression, correlation, association, annotated
- ROC: binary versus multiclass
- Performance: single-model versus comparative
- Survival: standard versus stratified
- Networks: static, weighted, clustered, multilayer
- Embeddings: PCA, UMAP, t-SNE

Selection order inside a compatible subtype:

1. Human family/template grade
2. Resolved grade
3. Preferred family version
4. Preference strength
5. Scientific-question suitability
6. Statistical compatibility
7. Data-schema compatibility
8. Accessibility
9. Reproduction-validation status
10. Original visual-quality evidence

Use the preferred version when it is scientifically valid. Keep both styles when the preference is a tie. Do not default to a design marked Neither. Treat a simplified reproduction as provisional.

Blocked image rows have no template and no learning weight. They are layout slots for a user-supplied file.
